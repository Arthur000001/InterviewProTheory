# Правила работы агентов (InterviewPro)

Приветствую, агент! Это проект InterviewPro. При работе в данном рабочем пространстве строго соблюдайте следующие инструкции:

## 📂 Структура проекта
Внимание: структура проекта **нестандартная**. Главная страница находится не в корне!
- `scripts/` — скрипты логики (`quizlet_mode.js` и др.) и данные вопросов в `scripts/content/<раздел>/`.
- `styles/` — файлы стилей (`style.css` и др.).
- `view/` — здесь лежат главная `index.html` со всеми вопросами и каталоги тематических страниц. Вопросы, ответы и уточнения находятся в `scripts/content/<раздел>/`. Боковое меню и сборка страниц находятся в `scripts/site_runtime.js`.
- `.agents/` — здесь лежат дополнительные инструменты, скрипты на Python и расширенные инструкции.
- `.notes/` — справочная информация.

## ⚠️ Критические ограничения
1. **Не использовать Терминал для изменения файлов:** Категорически запрещено использовать `run_command` для редактирования файлов или навигации. Используйте только встроенные инструменты (`view_file`, `replace_file_content`, `multi_replace_file_content`, `write_to_file`, `grep_search`).
2. **Точечные правки:** Вносите изменения только после предварительного просмотра через `view_file`.
3. **Безопасность:** В файловой системе стоит запрет на запуск неизвестных бинарников (`noexec`).

## 📚 Расширенные правила
Обязательно ознакомьтесь с файлом `.agents/rules/interviewpro.md`, в котором содержатся детальные архитектурные ограничения и информация по проекту. Актуальный контекст сессий может находиться в `.agents/memory/CONTEXT.md`.
