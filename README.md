# InterviewPro

Статическая база из 436 вопросов и 342 уточнения для подготовки к техническим собеседованиям. Темы: SRE, Linux, сети, контейнеры, Kubernetes, базы данных, алгоритмы, Go, архитектура сервисов и безопасность. Есть теоретические вопросы, архитектурные разборы и задачи на чтение готового кода без написания решения. Каждый вопрос можно отметить как изученный и раскрыть нажатием на его текст. Уточнения находятся внутри раскрытого основного вопроса; после них есть ссылки на связанные вопросы.

## Запуск

Откройте `view/index.html` в браузере. Установка зависимостей и сервер не нужны.

## Структура

- `view/index.html` — главная страница со всеми вопросами, двумя квизами и собеседованием по таймеру.
- `view/<раздел>/<подтема>.html` — 51 тематическая страница с двумя квизами.
- `scripts/content/<раздел>/<подтема>.data.js` — вопросы, ответы и уточнения соответствующей подтемы. Каждый вопрос хранится в одном таком файле.
- `styles/` — оформление.
- `scripts/site_runtime.js` — боковое меню и сборка страниц из файлов подтем.
- `scripts/content/question_catalog.js` — названия вопросов и связи для переходов между ними.
- `scripts/content/archive_card_builder.js` — единый шаблон новых карточек и уточнений.
- `scripts/` — логика квиза, собеседования и копирования кода.

Правила работы агентов находятся в `AGENTS.md`.
