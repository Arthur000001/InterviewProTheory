# Checkpoints

Здесь хранятся точки возобновления работы над InterviewProTheory. Перед продолжением незавершённой задачи сначала читать `current.md`, затем только указанные в нём материалы.

Формат: Markdown. В каждом checkpoint кратко фиксировать цель, применённые изменения, проверенные факты, непроверенное, действующие ограничения и следующий допустимый шаг. Для проблемы с неудачными попытками обязательно сохранять число попыток и статус HARD STOP; новая сессия его не обнуляет.

`current.md` — единственная актуальная точка входа. Исторические снимки можно сохранять отдельными файлами с датой; они не заменяют `current.md`.
