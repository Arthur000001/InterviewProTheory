# Checkpoints

Здесь хранятся точки возобновления работы над InterviewProTheory. Перед продолжением незавершённой задачи сначала читать `current.md` и `index.json`, затем нужный отчёт в `reports/`.

Формат: Markdown. В каждом checkpoint кратко фиксировать цель, применённые изменения, проверенные факты, непроверенное, действующие ограничения и следующий допустимый шаг. Для проблемы с неудачными попытками обязательно сохранять число попыток и статус HARD STOP; новая сессия его не обнуляет.

Каждую существенную точку сохранять отдельным файлом в `reports/` и добавлять запись в `index.json`: короткое название, дата, время, ссылка на отчёт, состояние и число неудачных попыток. Если время или дата исторической точки неизвестны, указывать `null`, не подставляя время создания индекса. `current.md` — короткий указатель на последнюю точку и действующие HARD STOP; подробности работы в него не накапливать. Новая точка не стирает сведения о незавершённой работе и HARD STOP.
