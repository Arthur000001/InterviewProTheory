# Checkpoints

Здесь хранятся точки возобновления работы над InterviewProTheory. Единственная точка входа — `index.json`; полный текст каждой точки, включая последнюю, находится в `reports/`.

Формат: Markdown. В каждом checkpoint кратко фиксировать цель, применённые изменения, проверенные факты, непроверенное, действующие ограничения и следующий допустимый шаг. Для проблемы с неудачными попытками обязательно сохранять число попыток и статус HARD STOP; новая сессия его не обнуляет.

Для новой существенной точки сначала добавить запись в `index.json`: короткое название, дату, время, путь будущего отчёта, состояние и число неудачных попыток; обновить `latest_id`. Затем создать отдельный файл отчёта в `reports/`. После записи проверить JSON, существование указанного файла и соответствие статуса фактическому результату. Если время или дата исторической точки неизвестны, указывать `null`, не подставляя время создания индекса. Новая точка не стирает сведения о незавершённой работе и HARD STOP.
