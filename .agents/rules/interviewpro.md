# InterviewPro: Workspace Agent Rules

## 1. Архитектурный контекст
Проект **InterviewPro** — статическая база теоретических вопросов для подготовки к техническим собеседованиям.

1. 📚 **ТЕМАТИЧЕСКИЕ РАЗДЕЛЫ** (`view/<раздел>/<подтема>.html` и `scripts/content/<раздел>/<подтема>.data.js`) — единая база теории без разделения по компаниям. На 2026-10-03: 388 основных вопросов и 335 уточнений в 9 группах и 46 подтемах. Состав меняется; перед отчётом сверяйте фактические данные.
2. 🏠 **ГЛАВНАЯ СТРАНИЦА** (`view/index.html`) — все вопросы с уточнениями, два квиза и собеседование.
3. 🧠 **РЕЖИМЫ ПОВТОРЕНИЯ** (`scripts/quizlet_mode.js`, `scripts/interview_mode.js`) — квизы и собеседование по общей базе. `scripts/site_runtime.js` собирает страницы и боковое меню, добавляет метаданные ответов и независимый ориентировочный грейд уточнений.
4. 📊 **СТАТИСТИКА** — время (5 минут для основного вопроса, 2 для уточнения) и грейды сейчас являются учебными ориентирами. Числовой частоты собеседований для теоретической базы нет: «нет данных» и нейтральная окраска не означают низкую частоту. Классификацию по частоте не выдумывать. Грейд основного вопроса оценивается по теме, уточнения — отдельно по формулировке; эти оценки не проверены вручную.

## 2. Железные ограничения и правила исполнения (Inviolable Constraints)
- **🚫 ПОЛНЫЙ ЗАПРЕТ НА СПАМ ТЕРМИНАЛОМ (`run_command`):** В среде IDE включен интерактивный режим подтверждения консольных команд. Каждый запуск `run_command` выбрасывает пользователю навязчивое модальное окно. Все манипуляции с файлами выполнять **СТРОГО** через встроенные тихие инструменты (`view_file`, `replace_file_content`, `multi_replace_file_content`, `write_to_file`, `grep_search`, `list_dir`). Запуск терминала разрешен ТОЛЬКО по прямому указанию пользователя.
- **⚡ СКОРОСТЬ И ХИРУРГИЧЕСКАЯ ТОЧНОСТЬ:** Никакого раздувания пайплайнов и оверинжиниринга. Простые правки вносятся точечно и мгновенно. Никаких слепых замен — сначала просмотр через `view_file`.
- **🛑 ЗАПРЕТНЫЕ ЗОНЫ:**
  - `Archive/` — СТРОГО READ-ONLY.
  - `view/` — НЕ ТРОГАТЬ без прямого указания пользователя.
  - `git` — НЕ ТРОГАТЬ без прямого указания.
- **⚠️ ФАЙЛОВАЯ СИСТЕМА (`noexec`):** Раздел смонтирован с запретом выполнения бинарников (`noexec`). Прямой запуск бинарников завершается ошибкой 126.
- **🌐 LIVE PREVIEW:** Главная и общая страница вопросов — `view/index.html`, страницы подтем имеют уникальные имена.
- **🗣️ СТИЛЬ ОБЩЕНИЯ:** Никаких переспрашиваний, вопросов «сделать ли?», оправданий и пустых слов. Только сухой и точный отчет о сделанном.

## 3. Память проекта (Memory)
- Актуальный сводный контекст: `.agents/memory/CONTEXT.md`.
- Отчеты о сессиях сохранять короткими файлами (до 100 строк) в `.agents/memory/`.
- Точки возобновления хранить в `.agents/checkpoints/`: для каждой существенной работы — отдельный отчёт в `reports/` с фактами, неизвестным, числом неудачных попыток и действующими STOP. Перед продолжением читать короткий указатель `current.md`, JSON-индекс `index.json`, затем отчёт нужной задачи. При завершении существенной работы обновлять отчёт, индекс и указатель. Формат и порядок — `.agents/checkpoints/README.md`.
