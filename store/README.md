# Хранение состояния InterviewPro

В интерфейсе один профиль с начальным именем `artur`. Имя можно поменять кнопкой
✎ рядом с ним. Для каждой темы в `store/data/<имя>` хранится отдельный JSON,
например `golang__basics.json`. Он содержит вопросы, уточнения и их статусы.
Каталог `store/data/artur` уже создан; в его исходных файлах статус `null`
означает, что отметки пользователя пока известны только браузеру. Кнопка
сохранения запишет текущие отметки как `true` или `false`. Прежний каталог при
переименовании не удаляется.

При первом нажатии «Сохранить состояние текущих вопросов в JSON» браузер
попросит выбрать `InterviewProTheory/store/data/artur`, `InterviewProTheory/store/data`
или `InterviewProTheory/store` и разрешить запись. По одному
относительному пути страница не может получить доступ к файлам на диске.
Браузер попытается запомнить выбранную папку; если разрешение сброшено, оно
будет запрошено снова. Сайт проверяет имя папки, но не её абсолютный
путь — нужную папку проверьте в диалоге браузера.

Загрузка состояния текущего имени находится в окне «Отметить по номерам» на странице итогов.
Текущие отметки браузера не удаляются при неудачной записи. Если браузер не
поддерживает выбор папки, запись в `store/data/<имя>` недоступна.
